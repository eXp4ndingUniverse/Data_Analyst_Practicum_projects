# Исследование продаж билетов сервиса Яндекс Афиша

## Описание проекта

Исследовательский анализ данных пользователей сервиса Яндекс Афиша для выявления ключевых факторов, влияющих на потребительский спрос на билеты. В рамках проекта проанализированы три набора данных:

* Заказы билетов — информация о покупках, пользователях, устройствах и выручке.
* Мероприятия — данные о событиях, их типах, регионах и площадках.
* Курсы валют — курс казахстанского тенге к российскому рублю за 2024 год.

В рамках анализа были поставлены следующие задачи:

* выявить сезонную динамику заказов и изменение спроса осенью;
* сравнить поведение пользователей мобильных и десктопных устройств;
* определить популярные категории мероприятий, регионы и билетных партнёров;
* проверить статистические гипотезы о различиях в активности пользователей;
* сформировать практические рекомендации.

## Навыки и стек технологий

**Язык и библиотеки:** Python, pandas, matplotlib, scipy.

**Навыки:** обработка и очистка данных (merge, drop_duplicates, работа с пропусками), преобразование типов данных, агрегация данных (groupby, pivot_table), визуализация данных (гистограммы, столбчатые и линейные диаграммы), статистический анализ (проверка гипотез, t-тест).

## Общий вывод

В ходе проекта проведён исследовательский и статистический анализ продаж билетов на основе трёх датасетов (290 849 заказов, 22 427 мероприятий, 357 записей о курсе валют). После объединения и очистки итоговый датасет составил 290 571 строку (потеря — 0,1 %). Анализ выявил ключевые тренды спроса (сезонность, региональные особенности, различия по устройствам) и позволил сформулировать прикладные рекомендации для бизнеса. Подтверждены гипотезы о более высокой активности пользователей мобильных устройств.
