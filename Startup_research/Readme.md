# Исследование стартапов

## Описание проекта

Исследование закономерностей финансирования стартапов и оценка перспектив выхода на рынок с покупкой и развитием компаний. В ходе работы проведён исследовательский анализ данных о компаниях и объёмах привлечённых инвестиций, а также о возвратах по типам финансирования.

В ходе анализа были поставлены следующие задачи:

* загрузить и изучить данные;
* выполнить предобработку и очистку данных;
* проанализировать распределение компаний по срокам финансирования;
* выделить и классифицировать сегменты рынка (массовые, средние, нишевые);
* выявить аномальные объёмы финансирования;
* проанализировать динамику финансирования по годам и сегментам рынка;
* оценить возвратность различных типов инвестиций;
* сформулировать практические рекомендации.

## Навыки и стек технологий

**Язык и библиотеки:** Python, pandas, matplotlib, seaborn.

**Навыки:** обработка и очистка данных (преобразование типов данных, работа с пропусками, удаление дубликатов), создание новых категориальных переменных (группы по срокам финансирования, сегментация рынков), агрегация данных (groupby, pivot_table), анализ выбросов (метод IQR), визуализация данных (круговые диаграммы, гистограммы, линейные и столбчатые графики).

## Общий вывод

В ходе проекта был проведён анализ данных о финансировании стартапов (54 294 записи). После очистки и обработки данных для анализа осталось 40 905 строк (потери ~24,7%). Основной объем инвестиций приходится на компании с долгосрочным финансированием — они получают более 60% всех средств. Венчурное финансирование — лидер по возвратам (70%). В 2014 году зафиксирован спад активности, свидетельствующий о перестройке рынка. Наиболее уверенный рост демонстрируют медицинский сектор и дизайн.
